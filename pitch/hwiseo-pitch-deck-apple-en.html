04 Solution · Defending authorship
Authorship
A different test
Not how much it is distorted — who authored it
  • Autobiographical memory is reconstructive by nature
  • Family talk in the era of prints distorted it just the same
  • Distorted by the user recalling it — that is their memory
  • Created because the AI suggested it — that is the AI's · the line
Working rule
Open the channel,
never supply the content
  • “Do you remember the smell that day?” — opening a channel
  • ✕ “Was it maybe the smell of rain?” — supplying content
  • “It looks like …, is that right?” — checking a misread
  • ✕ “You're under a pink blanket.” — asserting a misread
Triple defence on the four panels
  • Hand-drawn illustration — never photographic
  • Shown beside the original photo
  • Captions quote what was said — traceable
Tone rules
  • No blanket agreement · never name the emotion
  • The AI never fills in “I don't remember”
  • No comments on appearance · clothes and objects allowed
Ethical safeguards
  • For the 47% who avoid a period — skip
  • Move on at once, without asking why
  • No AI face · states plainly that it is an AI

A02 Research · Peer-reviewed evidence
Peer-reviewed
Henkel 2014 · Psychological Science
Taking a photo offloads the memory
  • Worse memory for what was photographed — object, detail and location alike
  • Exception — zooming in on a detail preserves the memory
  • Implication: what you attend to is what stays = what Hwiseo does
  • The empirical version of Sontag's On Photography (1977)
Roediger & Karpicke 2006
Retrieval beats re-exposure
  • After 5 minutes — rereading 83% / retrieval 71%
  • After 1 week — rereading 40% / retrieval 61% · reversed
  • Rereading wins in the short term, and people overrate it
  • The strongest answer to “can't I just scroll?”
Hirst & Echterhoff 2012 · Annual Review
A memory drawn out in conversation stays differently
  • Elaborative reminiscence = consolidation of autobiographical memory
  • Shared reality — positively correlated with psychological well-being
  • Taught as an intervention technique in care settings
  • Stated honestly — collaborative inhibition is also reported
Lucas et al. 2014 · Computers in Human Behavior
People disclose more to an AI than to a person
  • More disclosure to a virtual interviewer than a human one
  • Mechanism — the sense of not being judged
  • Framing it as a computer lowers evaluation anxiety and impression management
  • Design conclusion — never hide that it is an AI · no face avatar
A03 Research · A validated protocol
Method
Fisher & Geiselman 1992 · 40 years of validation
Cognitive Interview · 인지 면담
+41% correct detail Over 90% accuracy in the field
  • Context reinstatement — a stage, not a question
  • Report everything — explicit permission that “even the trivial is fine”
  • Change order — “what were you doing just before that?”
  • Change perspective — “how did the person beside you see you then?”
Harper 2002 · Visual Studies
Photo Elicitation · 사진 유도 면담
  • Images and language are processed in different regions of the brain
  • The yield is not more information but a different kind of it
  • An established method in visual sociology, anthropology and public health
Definition
Hwiseo = photo elicitation
carried out by an AI

The photo's status — not the subject but the instrument.

Diagnosis of the failed first session — the problem was not the prompt but the absence of a protocol. Context reinstatement collapsed into a single question · no permission to report everything · demanding precise retrieval · no rule for switching axis.

A04 Tech · Stack decisions
Stack
Application
Next.js · App Router
  • Built-in route handlers — the API key stays hidden without a separate server
  • One web app, branched to exhibition / documentary by mode
  • UI = React
  • Only two screens — booth and phone
Where it runs
Two builds, one codebase
  • App prototype — local dev server · phone view
  • Exhibition build — a single next start process on the booth MacBook
  • No cloud deployment — launching is not the goal
  • Screens — phone for the app, MacBook 16:10 · 1440×900 for the booth
State
Server memory
  • No database · no schema · no migrations
  • A session dict — {sid: {image, messages, turn, ts}}
  • Only the conversation log is kept, as text JSON
  • A single process is what makes shared memory work
Model
An LLM that takes images
  • Starting with Claude — the final call is Korean question quality
  • Price is not a deciding variable
  • Local models ruled out — inference lag on a MacBook without a GPU
  • Prompt caching — roughly one third of the input cost

Options ruled out, and why — an iPad booth (the on-screen keyboard covers the photo) · cloud deployment (no on-site fixes, and photos persist off-site) · the macOS file picker on the MacBook (exposes personal files in Finder) · a local LLM (inference lag loses the visitor).

A08 Tech · Images and privacy
Pipeline
Phone · choosing
One photo from the album
  • <input type="file" accept="image/*">
  • Never use the capture attribute — it opens the camera
  • Exhibition mode takes one photo, without multiple
  • One button · a screen that needs no explanation
Phone · converting
Client-side resize
  • Long edge 1568px · JPEG quality 0.8
  • A 4–8MB original → about 300KB
  • An LTE upload over 10 seconds = the visitor walks away
  • It cuts token cost as well
Phone · correcting
EXIF · HEIC
  • createImageBitmap(f, {imageOrientation:'from-image'})
  • Without correction, portrait iPhone photos arrive on their side
  • HEIC is converted to JPEG through canvas
  • On the fallback path the server returns an explicit error
Server · retention
Nothing is stored
  • Held in memory only · discarded when the session ends
  • Nothing written to disk → no files to manage
  • The same wording appears at the foot of the phone screen and on the booth signage
  • All that remains is the conversation text log

Why we go into this much detail — a keepsake photo will almost certainly contain the faces of family and friends. That is personal data, and it is a likely question at the exhibition review. Test on a real iPhone and a real Android device, separately — finding it on the day is too late.

A09 Tech · Designed not to fail
Resilience
API failure
8-second fallback
  • Three sample sessions embedded in the app as JSON
  • Switches automatically if nothing responds within 8 seconds
  • The visitor never knows it switched
  • Network failure, quota exceeded and latency are all handled the same way
Total failure
Demo mode
  • A prepared photo with hard-coded responses
  • One keyboard shortcut to switch
  • Even at worst, there is still something to show the reviewers
  • The operator must know the shortcut by heart
Device
Kiosk
  • Chrome kiosk mode — no reload, no address bar
  • Wake Lock API keeps the screen on
  • Sleep and screensaver off, power adapter always connected
  • Closing the lid kills the server
Security
  • The API key lives only in .env server environment variables — never a NEXT_PUBLIC_ prefix
  • Every model call goes through the server. On a public URL, anything in the front end leaks instantly
  • 10MB upload cap + MIME check + no upload without knowing the sid
Checklist for the day
  • Confirm the QR points at today's tunnel address, not yesterday's
  • Rehearse on real iOS and Android devices; set the API usage cap
  • Freeze production — no deploys during the exhibition
A10 Tech · Prompt operations
Prompts
Principle
A prompt is data, not code
  • /prompts/analyze.v1.md · ask.v1.md · compose.v1.md
  • It must be tunable without a deploy — changing one costs almost nothing
  • Record prompt_version and model per session → A/B comparison
  • Written so it can go on the panel as-is — this is a design deliverable
The ask prompt · rules from the research
Ten clauses
  • ① Context reinstatement first, as a stage · ② say “even the trivial is fine” explicitly
  • ③ Prefer what was repeatedly present · ④ clothes and objects allowed, never appearance
  • ⑤ A checking tone, never assertion · ⑥ open the channel, never supply the content
  • ⑦ The AI never fills in “I don't remember” · ⑧ switch axis after two misses
  • ⑨ Never agree unconditionally · ⑩ reorder the layers to suit the type of photo

How it is validated — prompt quality is judged by user testing, not code review. 2–3 sessions in W3, 5–6 in W4 (mixed generations). No documentary shooting before the prompts are locked on 9/17 — if the footage runs ahead of the product, the film becomes a lie.
