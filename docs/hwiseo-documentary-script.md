# 휘서(HWISEO) 다큐멘터리 — 스크립트 아이디어 풀

> **성격:** 프로모션 영상(v3.1)과 **별개 건**.
> 휘서 AI 챗봇을 실제로 사용하는 사람들의 모습 + 사용 후 인터뷰를 담은 실사용 기록물.
> 아래는 떠오르는 대로 받은 원문 그대로의 아이디어 풀. 정리·구조화는 나중에.

## A. 인터뷰 질문

### A-1. 사전 인터뷰 (사용 전) — 사진과의 관계 파악
> 휘서를 쓰기 전, 피사자가 평소 사진을 어떻게 대하는지 자기 입으로 말하게 하는 블록.

1. 사진을 직접 인화해 본 경험이 있나요?
2. 휴대폰에 있는 사진을 얼마나 자주 들여다보나요?
3. 최근에 예전 사진을 다시 본 적이 있나요?
4. 사진 찍기 더 쉬워지면서 아쉬운 점?

#### A-1-b. 함께 본 경험 (타인과의 앨범)
> 사진 보기가 원래는 **혼자 하는 일이 아니었다**는 걸 본인 입으로 말하게 하는 블록.
> 질문을 던져주던 옆사람의 자리가 비어 있다는 사실이 드러나야, 휘서가 왜 묻는지가 성립함.
> 배치: A-1의 3번(최근에 예전 사진 다시 본 적) 뒤, 4번(아쉬운 점) 앞.

5. 누군가와 앨범을 같이 넘겨본 적 있으세요? 언제, 누구랑요?
6. 그때 옆에 있던 사람이 사진 보면서 무슨 얘기를 했는지 기억나세요?
   → (핵심) 사진 자체보다 **그 사람이 꺼낸 말**이 기억에 남는다는 걸 스스로 말하게 하는 질문
7. 앨범 같이 보자고 먼저 꺼낸 쪽은 누구였어요?
   → 물어봐주는 사람이 따로 있었다는 사실을 드러냄
8. 사진에는 안 찍혀 있는 얘기까지 나왔던 적 있죠? 어떤 얘기였어요?
9. 요즘은 휴대폰 사진을 누군가한테 보여준 적 있으세요? 그때는 어땠어요?
   → 앨범(같이 앉아 넘김) vs 폰(내가 넘기고 상대는 봄)의 대조
10. 내 사진들, 나중에 누가 봐줬으면 좋겠다는 생각 해본 적 있으세요?

**❌ 배제 (보류)**
- ~~"지금은 물어볼 수 없는 사람이 찍힌 사진이 있나요?"~~
  → **질문지에서 제외.** 위험 대비 얻는 것이 불확실하고, 인터뷰가 거기서 멈출 수 있음.
  → **데스크 리서치 완료 후 재검토.** 그때 다시 판단한다.

### A-2. 직후 인터뷰 (사용 끝나고 5분 안)
> 감정이 식기 전에. 정리된 소감이 아니라 아직 안 정리된 말을 받아야 함.

1. 방금 뭐가 떠올랐어요? 그거 마지막으로 생각해본 게 언제예요?
2. 휘서가 던진 질문 중에 예상 못 했던 게 있었어요?
3. 방금 하신 그 얘기, 누구한테 해본 적 있어요?
4. **(사전 인터뷰와 동일 질문 — 대조용)** 이 사진, 왜 고르셨어요?
5. 기계가 물어봤다는 게 이상하진 않던가요? 사람이 물었으면 달랐을까요?

### A-3. 며칠 뒤 재방문 — **확정 구성에서 제외** (보류, 여유되면)
1. 그 뒤로 사진 다시 들여다본 적 있어요?
2. 그날 한 얘기, 누구한테 해봤어요?

## B. 현장 / 촬영 장면

### B-1. 사용 장면 — 화면 + 얼굴 동시 수록 (확정)

- 챗봇 '휘서'를 사용하는 장면은 **화면 녹화**로 잡는다.
- **화면 녹화와 얼굴 리액션을 동시에** 잡을 것. 사용하는 과정 전체.
  - 화면: 기기 자체 화면 녹화 (외부 카메라로 모니터 찍지 말 것 — 글자 뭉개짐)
  - 얼굴: 별도 카메라 1대, 화면을 내려다보는 눈높이가 걸리는 각도
- **싱크 확보:** 시작 시 손뼉 한 번 or 화면에 타이머 띄우고 얼굴캠에도 잡히게.
  두 소스를 편집에서 붙여야 "질문이 뜬 순간 → 그 얼굴"이 성립함.
- 사용 중 진행자 발화 금지. 침묵도 그대로 둘 것.

## C. 나레이션 · 자막 · 구조

### C-0. 편집 방침 — 사용 장면 압축

**원칙:** 사용 장면은 실시간 전량이 아니라, **중요한 순간·리액션만 강조**해서 압축한다.

**⚠️ 자를 것 / 남길 것 — 겉보기엔 둘 다 "아무 일 없는 화면"이라 같이 날아가기 쉬움**

| | 정체 | 처리 |
| :-- | :-- | :-- |
| 로딩 대기, 오타 수정, UI 헤맴, 사진 고르는 스크롤 | 기계적 지연 (남겨두면 서비스가 굼떠 보임) | **자름** |
| 질문 읽고 답이 안 나오는 3초 침묵 | **기억이 올라오는 시간 = 이 다큐의 증거 본체** | **남김** |

> 이 침묵을 다 잘라내면 "질문을 받으면 사람이 멈춘다"는 증명이 사라지고 챗봇 시연 영상이 된다.

**편집 시 구별 기준 — 손과 시선**
- 손이 움직임 → 조작 중 → 자름
- 손이 멈추고 시선이 화면 밖으로 → 회상 중 → 남김
- ∴ **얼굴캠 앵글에 손이 같이 걸려야 한다.** 얼굴만 클로즈업하면 나중에 구분할 근거가 없음.

**화면과 얼굴을 같은 속도로 자르지 않는다**
브리프 10장 = C유형(인터뷰 촬영 + **화면 인서트 후반 합성**), "화면 인서트는 편집 기간에 붙이거나 후반 교체 가능".
→ 화면은 원본 녹화 그대로가 아니라 **후반 재구성** 가능.

| 소스 | 처리 |
| :-- | :-- |
| 화면 | 후반 재구성. 질문 또렷하게, 답변 타이핑 적당한 속도. 로딩·오타·헤맴 없음 |
| 얼굴 | 실시간 그대로. 압축하지 않음 |

시간 압축을 화면 쪽에서만 하므로 얼굴의 감정 흐름이 끊기지 않는다.
이 영상의 진정성은 화면이 아니라 **얼굴**에 있으므로 화면을 정돈해도 손상되지 않는다.

**컷 리듬**
질문이 뜨는 순간 → 화면 / 침묵 3초 → 얼굴 / 말이 터짐 → 얼굴 유지 / 답변이 쌓임 → 화면 인서트

### C-1. 인터뷰 전체 구성 (제안)

**대전제 — 촬영 순서 규칙:** 사전 인터뷰는 반드시 휘서를 **만지기 전에** 찍는다.
한 번 쓰고 나면 "예전엔 그냥 넘겼었죠"가 전부 회고가 되어버림.
쓰기 전 상태 그대로의 증언이 확보돼야 사용 후와의 대조가 성립한다.

| 블록 | 내용 | 길이 | 카메라 |
| :-- | :-- | :-- | :-- |
| 1. 사전 | 사진과 나의 거리 (A-1) | 5~7분 | 인터뷰 세팅 |
| 2. 사용 | 개입 없음. 진행자 발화 금지 | 실사용 그대로 | 화면 녹화 + 얼굴 1대 |
| 3. 직후 | 감정 식기 전 (A-2) | 5분 내 | 인터뷰 세팅 |

※ **확정 구성은 3블록:** 사용 전 인터뷰 → 사용 화면 → 사용 후 인터뷰.
（며칠 뒤 재방문은 보류）

**편집 구조 — 인물 순차가 아니라 주제 교차** (루즈함 방지)

| 구간 | 등장 | 리듬 |
| :-- | :-- | :-- |
| 사용 전 | **5명 전원 교차** | 질문 하나에 5명 답이 연달아 → 다음 질문. 빠르게 |
| 사용 장면 + 직후 | **2~3명만** | 감정은 한 사람에 머물러야 생김. 인물을 바꾸면 매번 처음부터 쌓아야 함 |
| 마무리 | 5명 한 마디씩 | 열어주고 닫음 |

> **촬영 5명 ≠ 등장 5명.** 5인은 욕심이 아니라 보험 — W5 한 주에 촬영, 9/24 하드 마감,
> 재촬영 슬롯 없음. 얼어붙거나 기억이 안 터지는 사람이 나올 수 있고, 다큐의 역할이
> "증거"이므로 인원이 줄면 증거가 안 선다. 결과가 좋은 사람은 중반으로 승격.

**블록 2에서 반드시 잡아야 할 4순간**
1. 질문 받고 **멈추는** 순간 (침묵 자르지 말 것)
2. 웃거나 표정이 무너지는 순간
3. 답이 길어지는 순간 — 한 줄 답하려다 계속 말하게 되는 지점
4. 완성된 이야기를 **읽는** 순간의 얼굴

**섭외:** 세대를 섞을 것. A-1 1번(인화 경험)이 세대 대조를 만들어냄.
필름/인화 세대와 무한 재현 세대가 같은 질문에 다른 답을 하는 것 자체가 구조가 된다.

## E. 섭외 — 5인 구성 (확정)

| # | 대상 | 자리 | 섭외 상태 |
| :-- | :-- | :-- | :-- |
| 1 | **어머니 (50대 여)** | 인화·앨범 세대 | 확보 |
| 2 | **아버지 (50대 남)** | 인화·앨범 세대 | 확보 |
| 3 | **30~40대 (전환기 세대)** | 필름 → 디카 → 폰 전환을 몸으로 겪음 | 섭외 필요 |
| 4 | **20대 여** | 무한 재현 세대 | 섭외 필요 |
| 5 | **20대 남** | 무한 재현 세대 | 섭외 필요 |

### 캐스팅 원칙
- 성별 균형은 **결과로 따라오게** 두고, 실제 선별 축은 **사진과 맺은 관계**로 본다.
  - 실물 앨범이 집에 있는가
  - 사진을 정리하는 사람인가 / 방치하는 사람인가
  - 찍는 양 (하루 수십 장 vs 한 달 몇 장)
- 50대 부부는 이 축에서 붙어 있을 확률이 높음 → **20대 두 명을 서로 반대편으로** 고를 것.
  (강박적으로 정리하는 사람 하나, 갤러리 2만 장 방치하는 사람 하나)

### 인물별 메모
- **50대 부부**: 반드시 **따로따로, 서로 없는 자리에서** 촬영.
  같이 앉히면 한쪽이 다른 쪽 기억을 대신 말해서 두 인터뷰가 한 인터뷰가 된다.
- **30~40대**: 유일하게 **변화 자체를 증언할 수 있는** 사람.
  사용 전 인터뷰 4번(사진 찍기 쉬워지면서 아쉬운 점)이 이 사람에게서 가장 두껍게 나옴.
  ⚠️ **사진 수집 리스크**: 디카·싸이월드 시절 사진은 폰에 없고 외장하드·CD·구형 계정에
  잠겨 있을 확률이 높다. 이 한 명만 W4 사진 수집이 훨씬 오래 걸릴 수 있으므로 **가장 먼저 요청**할 것.
- **20대 2인**: 사용 전 인터뷰 1번(인화 경험)에 "없다"가 나올 가능성. 그 '없음'이 그대로 대비가 됨.

## F. 촬영 전 유저테스트 계획

**목적:** 다큐의 품질 = 촬영일에 휘서가 던지는 질문의 품질.
브리프 10장 — "5인이 답할 질문이 진부하면 인터뷰 자체가 진부해지고, **그건 편집으로 못 고친다.**"

**세션 단가:** 질문 5~7개 / 10분 내외 (브리프 5-2). 한 세션이 짧아 회수를 늘리기 쉽다.
비싼 건 세션이 아니라 **섭외 + 라운드 사이 프롬프트 수정**이다.

### 멈추는 기준 (숫자가 아니라 수확 곡선)
1차 세션 테스트에서 프롬프트 규칙이 **8개** 나왔다 → 아직 수확 초반.
- 라운드당 2~3명 → 라운드 끝날 때마다 프롬프트 수정 → 다음 라운드
- **새 규칙이 0~1개인 라운드가 2연속이면 중단**
- 경험적으로 12~16세션 근처에서 그 지점이 온다

### 일정 배치

| 시기 | 회수 | 방식 |
| :-- | :-- | :-- |
| W1~W2 (8/25–9/3) | 6~9회 | **개발 없이 수동.** 대화창에 프롬프트 붙여넣고 사람 앉히면 됨 |
| W3~W4 (9/4–9/17) | 5~6회 | 실제 프로토타입. UI·업로드·지연까지 포함 |

### ⚠️ 제약 3가지
1. **본 촬영 5인은 테스트에 절대 넣지 않는다.**
   이미 써본 사람은 카메라 앞에서 *처음 겪는* 반응이 안 나온다.
   특히 부모님 — 가까워서 테스트 대역으로 쓰기 쉬우므로 의식적으로 배제할 것.
2. **사진 유형을 흩을 것.** 1차가 셀피였고 "셀피는 배경 단서가 없어 금방 마른다"가 이미 발견됨.
   단체사진 / 풍경 / 실내 / 오래된 인화사진 등으로 층 순서 규칙을 유형별로 검증.
3. **세대를 섞을 것.** 20대만 테스트하면 50대에게 안 통하는 질문을 못 잡는다.
   부모님 세대 대역이 필요한데 부모님 본인은 쓸 수 없음 → 친척·이웃 등으로 확보.
