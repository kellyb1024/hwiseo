## 0. 지금 코드 상태 한눈에

| 폴더 | 정체 | 출시에 쓸 부분 |
|---|---|---|
| `app-prototype/` | 공개 앱 = hwiseo.vercel.app (PWA). 화면 17개(스플래시·불 켜기·온보딩·홈·채팅·스크랩북·미니게임·나·이 앱에 대해) | **앱의 겉모습·흐름의 기준.** 단, 대화는 미리 짜인 내용이고 사진도 샘플(`photos/`, `uploads/`)이라 실제 AI는 안 붙어 있음 |
| `exhibition-app/` | 전시용 아이패드 앱 + Vercel 서버 (`api/chat.js`, `summary.js`, `upload.js`, `photos.js`, `stats.js`) | **실제 Claude 대화 서버의 기준.** 사용량 기록(`_stats.js`)도 있음 |
| `hwiseo-app/` | Next.js 프로토타입 (`app/api/ask`, `app/api/compose`) | 키 없으면 목(mock) 모드로 도는 구조가 참고할 만함. 모델 이름 `claude-opus-5`는 확인 필요 |

**가장 큰 숙제:** 공개 앱(`app-prototype`)의 화면 + 전시 서버(`exhibition-app/api`)의 진짜 AI 대화를 **하나로 합쳐야** 해요.
지금 공개 앱을 그대로 내면 "데모/미완성 앱"(심사 조항 2.1) + "웹사이트를 감싼 앱"(4.2)으로 반려될 가능성이 커요.

## 1. 계정·돈

- ⬜ **Apple Developer Program 가입**: 연 129,000원(US$99)
  - 개인으로 가입하면 스토어 판매자 이름에 **본명**이 나와요
  - "휘서"로 보이게 하려면 사업자로 가입해야 해요(D-U-N-S 번호 필요)
- ⬜ **Claude API 결제 계정**: console.anthropic.com
  - ⚠️ **Claude.ai 구독(Pro/Max, 월 $100 등)은 앱에서 쓸 수 없어요.** 구독은 사람이 직접 채팅하는 용도예요. 앱 서버가 부르는 API는 Console에서 따로 충전하는 종량제예요. 구독 로그인 토큰을 앱 서버에 넣는 건 약관 위반이에요.
  - 전시용 키는 만료됐으니 **출시용 새 키**를 Console에서 발급받기
  - Console에서 **월 지출 한도** 걸기(예: $100). 사용자가 갑자기 늘어도 청구서가 폭발하지 않아요.
  - 키는 **Vercel 환경변수에만** 넣기. 앱 안(Xcode 프로젝트, JS 파일)에 넣으면 절대 안 돼요.
- ⬜ 모델 정하기: 지금 `exhibition-app/api/_claude.js` 기본값은 `claude-sonnet-5-5`예요. 비용을 아끼려면 `CLAUDE_MODEL=claude-haiku-5-5`를 쓰고, 대화 질이 괜찮은지 직접 써 보고 결정하기
- ⬜ 유료 기능(구독·인앱결제)을 넣으면 한국에선 **통신판매업 신고** + 애플 인앱결제 설정이 추가로 필요해요. 무료로 내면 해당 없어요.

## 2. 웹앱 → iOS 앱으로 만들기

- ⬜ **Capacitor로 감싸기**(권장): `app-prototype` HTML/JS를 거의 그대로 iOS 프로젝트로 만들 수 있어요
- 🟡 **외부 CDN 의존 없애기**
  - 지금 `support.js`가 React·Babel을 unpkg.com에서 받아오고, 브라우저 안에서 JSX를 변환해요
  - 앱에서는 첫 실행이 느리고, 인터넷이 없으면 아예 안 켜질 수 있어요
  - 빌드 단계에서 미리 변환해서 앱 안에 넣어야 해요
  - 폰트(Google Fonts, Pretendard jsDelivr)도 앱 안에 넣기
- 🟡 서비스워커(`sw.js`)는 앱 안에선 필요 없어요. PWA 설치 안내(`install-guide.js`)도 앱 버전에선 빼기
- ⬜ **기기 기능 붙이기**: 4.2 반려를 피하려면 웹사이트와 다른 이유가 있어야 해요
  - [ ] 진짜 사진첩에서 사진 고르기(지금은 샘플 사진 목업)
  - [ ] 진짜 푸시 알림(APNs): 온보딩 "알림 주기" 화면이 이미 있어서 연결만 하면 돼요
  - [ ] 햅틱(불 켜기, 스티커 오려내기, 게임)
  - [ ] (선택) 홈 화면 위젯: 오늘의 휘서·촛불
- 🟡 마이크: 채팅에서 `getUserMedia({audio:true})`를 써요. 계속 쓸 거면 권한 문구가 필요하고, 안 쓸 거면 빼는 게 심사에 유리해요.
- 🟡 공유: `navigator.share`는 Capacitor Share 플러그인으로 바꾸기

## 3. 서버(진짜 AI 대화)

- 🟡 `exhibition-app/api/chat.js`·`summary.js`를 출시용 서버로 옮기기. 전시용과는 분리된 새 Vercel 프로젝트로 만들기
- ⬜ **남용 막기**: 지금 chat API엔 횟수 제한이 없어요. 누구나 주소만 알면 내 키로 무한 호출할 수 있어요.
  - 기기별·하루 대화 횟수 제한(Upstash Redis는 이미 쓰고 있어서 재활용 가능)
  - 앱에서 온 요청인지 확인하는 장치(App Attest 등)
- 🟡 사진 보관 정책: 전시 서버는 30분 뒤 자동 삭제예요. 출시 앱은 "사진은 대화에만 쓰고 서버에 남기지 않는다"를 그대로 지키면 개인정보 설명이 쉬워져요.
- ✅ 사용량 기록(`_stats.js`, `/admin`)이 있어요. 출시 서버에도 가져가서 비용 확인용으로 쓰기
- ⬜ API가 실패할 때 미리 준비된 질문으로 넘어가는 장치. 전시 서버엔 있으니 그대로 유지

## 4. AI·개인정보 심사 포인트

- ⬜ **사진을 AI로 보내기 전 동의 화면**: "사진과 대화가 Anthropic의 Claude로 전송돼요"를 분명히 쓰고 허락받기(5.1.2). 온보딩 "A2 권한" 화면에 넣으면 자연스러워요.
- 🟡 **개인정보처리방침**: 앱 안 "이 앱에 대해" 화면에 안내문은 있어요. 웹에 공개된 **전문 URL**이 필요해요.
  - 수집 항목, AI 전송, 보관 기간, 삭제 방법을 적기
- ⬜ 앱 안 문의 메일 `hello@hwiseo.app`이 실제로 받을 수 있는 주소인지 확인하기. 도메인을 갖고 있는지도요. 아니면 실제 메일로 바꾸기.
- ⬜ **부적절한 대화 대비**: 시스템 프롬프트 안전 규칙 + "이 대화 신고하기" 버튼
- ⬜ 연령 등급 설문: "AI 챗봇/생성형 콘텐츠" 항목을 정직하게 체크하기
- ✅ "기록 지우기"가 '나' 화면에 있어요. 로그인을 만들지 않으면 계정 삭제 의무(5.1.1(v))는 해당 없어요. **로그인 없이 가는 걸 권장해요.**
- ⬜ App Store **개인정보 라벨**: 사진(대화 목적, 저장 안 함), 사용 데이터(서버 기록을 남기면)

## 5. Xcode 설정

- ⬜ 번들 ID(예: `com.kelly.hwiseo`), 버전 1.0.0, 빌드 번호
- ⬜ 권한 안내 문구(Info.plist)
  - `NSPhotoLibraryUsageDescription`: 예) "추억 사진을 보며 휘서와 이야기를 나누기 위해 사진에 접근해요"
  - `NSMicrophoneUsageDescription`: 마이크를 계속 쓸 경우
  - 푸시 알림 Capability
- ⬜ 세로 고정(manifest의 `portrait`과 맞추기), 아이폰 전용으로 할지 아이패드도 지원할지 정하기. 아이패드도 지원하면 스크린샷이 더 필요해요.
- ✅ 앱 아이콘: `design/icons/hwiseo-app-icon-2048.png` → 1024px로 줄여서 넣기
- ⬜ 실행 화면(Launch Screen): 보라 `#7B5CD6` 배경 + 마크

## 6. 스토어 등록 자료

- ⬜ 앱 이름: **AI 친구 휘서**(30자 이내) + 부제
- ⬜ 설명, 키워드, 카테고리: **라이프스타일** 권장
  - 미니게임이 있어도 "게임"으로 넣지 않기. 한국 게임 등급 문제가 생길 수 있어요.
- ⬜ 스크린샷: 6.9인치 아이폰 1320×2868, 3~10장. 그림체·쨍한 컬러 규칙 지키기
- ⬜ (선택) 앱 미리보기 영상: 홍보 영상(`promo-video/out/`)을 세로 짧은 버전으로 다시 편집
- ⬜ 지원 URL(문의 페이지), 개인정보처리방침 URL
- ⬜ 심사 메모: 앱 사용법 + "로그인 없음" + 테스트용 사진이 필요하면 안내

## 7. 테스트 → 제출

- ⬜ TestFlight로 내 폰 → 지인 몇 명 테스트
  - 사진 고르기 → 대화 → 스티커 → 스크랩북 흐름이 끝까지 되는지
  - 인터넷이 끊겼을 때·API가 실패했을 때도 멈추지 않는지
- ⬜ 심사 제출: 보통 1~3일. AI 앱은 한두 번 반려되기 흔하니 반려 사유를 보고 고쳐서 다시 내기

## 순서 제안

1. Apple 개발자 가입 + Console API 키·지출 한도 설정
2. 공개 앱 화면 + 전시 서버 AI 합치기(사진첩 → 진짜 대화)
3. 서버에 횟수 제한·동의 화면 넣기
4. Capacitor로 감싸기 + 푸시·햅틱
5. 개인정보처리방침 페이지 + 스토어 자료
6. TestFlight → 제출
