# 휘서 컨셉 영상 — 컷별 이미지 브리프 v1

> 원칙: **추상 도형 금지. 대사가 말하는 것을 그대로 그린다.**
> "기억"이면 사람 머리 안의 엉킨 실, "라벨"이면 진짜 사진 위에 붙은 라벨.
> 관객이 나레이션을 못 들어도 그림만으로 무슨 말인지 알아야 한다.

## 생성 공통 프롬프트 (모든 컷 앞에 붙임)

```
White chalk line drawing on a solid pure black background. Hand-drawn,
slightly rough chalk texture, thin-to-medium uniform lines. NO color, NO
shading, NO gradients, NO fill — outlines only. Minimal, clean, TED-Ed
style educational illustration. Single scene, 16:9, wide composition with
empty margins. No text, no letters, no watermark.

Scene: [아래 컷별 내용]
```

- **배경은 반드시 순검정** — 코드가 screen 블렌드로 얹으므로 검정은 투명처럼 사라진다
- **색은 넣지 않는다** — 색은 코드의 빛 레이어와 촛불만 담당
- **글자 넣지 않는다** — 라벨·한자는 코드가 그린다 (폰트 일관성)
- 한 컷에 한 장면. 여러 순간이 필요하면 컷을 쪼갠다 (아래 a/b/c)

## ★ 마지막 빛의 규칙 (2026-08-25 확정)

**하나의 빛이 퍼지는 게 아니라, 여러 색이 하나씩 켜진다.**
잊혔던 감각이 떠오를 때마다 색 하나가 켜진다 — 화이트아웃 없음.

| 감각 | 색 (안) |
| :-- | :-- |
| 케이크 냄새 · 김 | 주황 `#F08A4B` |
| 노래 · 음표 | 하늘 `#8FB3D9` |
| 촛불 끄는 입김 · 온기 | 앰버 `#E9A24A` |
| 포장지 · 손끝 | 연두 `#B8D68A` |
| 웃음소리 | 분홍 `#F2A6B8` |

C22에서 하나씩 켜지고(대사 "연달아"에 맞춰 순차), C23에서 다섯 색이 다 켜진 채 사람을 비춘다.
색이 쌓여서 밝아지는 것이지 배경이 하얘지는 것이 아니다. C24 타이틀은 다섯 색이 남아 있는 어둠 위에.

## 컷 분할 요약

원래 24컷 → **30장면** (C02, C09, C16, C17이 쪼개짐). VO 타이밍은 그대로,
한 VO 안에서 이미지가 바뀌는 방식이라 `cuts.ts`는 안 건드리고 장면 컴포넌트 안에서 전환.

## 이미지 받으면 코드가 하는 일

- 분필 보일 (3프레임마다 미세 떨림) · 종이 결 · 약한 글로우
- draw-on 마스크 (그어지듯 등장)
- 광원 주변 미세 색 물듦 (촛불·불씨·시선 — 배경 전체 아님)
- 라벨 텍스트 · 輝/敍 · 자막 · 타이틀
- 컷 내 카메라 (느린 푸시인, 드리프트)
