# 휘서 프로모션 영상 — 대본 v4 (문장 단위)

- **단위 원칙**: 한 문장 = 자막 한 장 = 나레이션 한 호흡 = 비주얼 한 비트
- **음성**: 영어 더빙 / **자막: 한국어 단독**
- **자막 규격**: 최대 2줄, 한 줄 25자 이내
- ⚠️ **한국어가 본문이다.** 전시장 관람객은 듣지 않고 읽는다
- 시간은 **가녹음 실측 전까지 미정** — 아래 표의 `#`만 확정

### ★ 발견 — 떠오름의 대칭
Part 1에서 **사진이 위로 떠올라 손이 닿지 않는 것 = 상실.**
Part 5에서 **이야기가 빛으로 떠오르는 것 = 전달.**
같은 움직임인데 의미가 뒤집힌다. 영상의 첫머리와 끝이 대칭을 이루므로 **의도적으로 같은 모션 언어를 쓸 것.**

## 영상에 넣을 예시 장면 (검토)

> **목적**: "그냥 스크롤해서 보면 되잖아"를 이기는 것.
> 추상 논증보다 구체적 장면 하나가 강하다. Part 4 또는 5에 짧게 삽입.

### 예시 A · 떨렸던 발표 → 면접의 용기
언젠가 떨면서 했던 발표의 기억을 꺼내, 그것을 용기 삼아 면접을 해낸다.
→ **과거의 기억이 현재를 살아가는 재료가 된다.** "보존이 아니라 동행"의 실증.

### 예시 B · 내 기억에 없는 나 ★ 더 강함
엄마 아빠가 보던, **내 기억에는 없는** 어릴 때의 사랑스러운 내 모습.
그걸 보며 어른이 된 내가 **"정말 많이 사랑받았구나"** 하고 위로받는다.

→ **스크롤로는 절대 도달할 수 없는 영역**이다. 내 기억이 아니라 부모의 기억이므로,
   아무리 봐도 나에게선 아무것도 나오지 않는다. **물어봐야 열린다.**
→ 최대 방어 과제의 3번을 장면 하나로 증명한다.
→ 세대 간 축이 억지 없이 되돌아오는 자리이기도 하다.

### 제작 판단
- **B를 우선 채택.** A는 시간이 남으면
- 두 장면 모두 **새 에셋이 필요**하다 (발표 장면 / 아기 사진과 어른의 뒷모습)
- 길이는 각 5~8초. 나레이션 1~2카드 분량
