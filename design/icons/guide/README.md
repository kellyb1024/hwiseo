# 휘서 앱 아이콘 — 작업 가이드

일러스트레이터에서 `guide-1024.svg` 를 열고, 가이드 그룹을 **잠그거나 숨긴 뒤** 그 위에 그린다.
가이드 자체는 내보낼 때 지운다.

## 파일

| 파일 | 용도 |
| :-- | :-- |
| `guide-1024.svg` | 1024 캔버스 + 안전영역·여백·중심선·스쿼클 |
| `squircle-1024.svg` | iOS 스쿼클 도형 하나 (배경/클리핑용) |
| `palette.svg` | 색 스와치 — 스포이드로 찍어 쓰기 |
| `build-guide.py` | 위 두 SVG 재생성 (`python3 build-guide.py`) |

## guide-1024.svg 안의 그룹

일러스트 레이어 패널에 그룹명으로 뜬다. 필요 없는 건 숨기면 된다.

| 그룹 | 뜻 |
| :-- | :-- |
| `01-캔버스-1024` | 아트보드 경계 |
| `02-중심선-삼등분` | 십자·삼등분선 + **광학 중심**(기하 중심보다 26px 위 — 사람 눈엔 여기가 가운데로 보인다) |
| `03-여백-6퍼센트` | 61px. 요소를 이 밖으로 내지 말 것 |
| `04-마스커블-안전원` | **지름 80% (r=410).** 밖은 잘린다고 보고 그린다 |
| `05-안드로이드-최소보장` | 66/108dp (r=313). 여기 안은 어떤 런처에서도 안전 |
| `06-iOS-스쿼클` | iOS 가 실제로 씌우는 마스크 (슈퍼타원 n=5) |
| `07-원호라운드-r229` | 일러스트 둥근사각형. 스쿼클과 비교용 — 모서리가 더 각지다 |

## 모서리 규칙

**앱에 넣을 파일은 모서리를 둥글게 만들지 않는다.** OS 가 자기 마스크를 씌우기 때문에,
미리 깎으면 이중으로 잘려 모서리에 빈 공간이 생긴다.

| 파일 | 모서리 |
| :-- | :-- |
| `apple-touch-icon.png` (180) | 정사각형. **알파 채널 없이** (투명 있으면 앱스토어 리젝) |
| `icon-512-maskable.png` | 정사각형 풀블리드 |
| `icon-192` / `icon-512` (`purpose:any`) | 둥글게 그려두는 게 무난 |
| `favicon.png` (64) | 둥글게 |
| 발표자료·영상용 | 둥글게 |

둥글게 그릴 때 반경 = **한 변의 22.37%**

| 변 | 1024 | 512 | 192 | 180 | 64 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 반경 | 229 | 115 | 43 | 40 | 14 |

Figma 로 간다면 반경 + **corner smoothing 60%** 가 iOS 와 거의 같다.
일러스트에는 그 기능이 없으니 `squircle-1024.svg` 를 쓰거나, 원호로 그리고 넘어간다.

## 일러스트 세팅

- 아트보드 1024×1024, 컬러모드 **RGB**
- 픽셀 그리드에 정렬
- 내보내기 **PNG-24**, 배경 불투명
- 512·192·180·64 는 1024 에서 줄여서 뽑는다

## 확인할 것

- **28~40px 에서 읽히는가.** 여기서 뭉개지면 다시.
- **원형으로 잘라도 되는가.** 마스커블본은 안전원 안에 다 들어와야 한다.
- 배경은 **단색**. 그라데이션 ✗ (캐릭터 안 광택은 괜찮다)

## 함정

1. `design/screens/hw-character.js` 는 **옛날 불꽃머리 캐릭터**다. 지금 휘서는 `design/character/hwiseo-F.js`.
2. 배경을 나중에 다른 색으로 갈아끼우려 하지 말 것 — 촛농이 배경과 같은 계열이면 잘라낼 때 양초가 깎인다. 배경색은 처음부터 정하고 그린다.
3. `hwiseo-app/public/manifest.json` 의 `background_color` 가 아직 옛 팔레트(`#EADFED`)다. 아이콘 바꿀 때 `#7B5CD6` 으로 같이 맞출 것.
