# 휘서 캐릭터 스펙 (2026-08-25)

일러스트레이터 작업용. 확정 방향은 **각진 원통 초 + 촛농 앞머리 + 촛농 밑단**.

## 색값

| 자리 | HEX |
| :-- | :-- |
| 왁스 본체 | `#EFEAF2` |
| 촛농 · 밑단 (진한 쪽) | `#D8D0E4` |
| 불꽃 바깥 (연보라) | `#B3A5DC` |
| 불꽃 코어 (노랑) | `#FFD34A` |
| 눈동자 | `#FFD34A` |

## 형태 규칙 — 어긋나면 망가지는 것들

시행착오에서 실제로 확인된 것들. 그리면서 지킬 것.

1. **목·허리를 만들지 말 것.** 상체 전체가 하나의 연속된 왁스 덩어리여야 한다.
   머리와 몸을 분리하는 순간 사람 해부 구조가 되어 기괴해진다. (실측 확인됨)
2. **머리가 몸통보다 넓어지면 안 된다.** 위가 무거워지면 불안정해 보인다.
3. **촛농 갈래는 서로 떨어져 있어야 한다.** 붙으면 즉시 단발머리로 읽힌다.
   갈래는 3~4개, 길이는 제각각, 끝은 뭉툭하게, 사이로 초 표면이 비치게.
4. **팔은 몸통 옆 높은 위치에 붙이고 살짝 아래로.** 허리 높이에서 수평으로
   뻗으면 허수아비처럼 보인다.
5. **다리 없음.** 밑단이 바닥에 닿아 실루엣을 닫는다.
6. **큰 진한 색면 금지.** 전체가 연해야 인쇄 잉크도 덜 먹고 가벼워 보인다.

## 인쇄 · 벡터 조건

- 평면 채색만. 그라데이션 · 그림자 · 글로우 · 텍스처 없음
- 아웃라인 굵기 균일
- 모든 도형은 닫힌 패스
- 배경은 순백 `#FFFFFF` (투명 PNG는 생성 단계에서 격자를 그림으로 그려버리므로 쓰지 않음)

## 미확정

- 불꽃 크기 — 현재 전체 높이의 약 20%. 키우지 않기로 함 (2026-08-25)
- 몸통 비율 — 현재 세로가 김
- 앱 아이콘 · 파비콘: 캐릭터를 축소해 쓸지, 디자인 시스템의 심지 마크를 쓸지
