## 1. 캐릭터 수정안

### 1-1. 조형 — 아웃라인을 버리고 두 도형으로

캐릭터/03(★)의 불꽃 실루엣과 아이콘/10~13의 촛불 마크를 합친다.
**불꽃 + 왁스, 두 덩어리.** 선 없음, 하이라이트 없음, 촛농 디테일 최소.

```
        ▲            불꽃  #FFD54A  (--main 과 동일 → 팔레트 어긋남 해소)
       ▲▲▲           ·  단계에 따라 크기·갈래 수가 변한다
        │            심지  #1D1B22  짧은 막대 하나
   ┌────┴────┐
   │  ●   ●  │       왁스  #B9A3F2  (연보라 · 흰 바탕과 노랑 바탕 양쪽에서 보이는 밝기)
   │    ‿    │       눈    흰자 #FFFFFF + 눈동자 #1D1B22   ← 표정은 여기서만
   └∪∪∪∪∪∪∪┘         밑단  스캘럽(물결) — 촛농이 굳은 자리. 캐릭터/03 'upset' 실루엣과 같다
```

- 지금 `character-spec.md`의 형태 규칙 1~6(목 없음·머리 좁게·촛농 분리·팔 위쪽·다리 없음·진한 면 금지)은 **그대로 유효.**
  바뀌는 것은 **"아웃라인 균일" → "아웃라인 없음"** 하나.
- 촛농 갈래는 **120px 이상에서만** 왁스보다 한 단계 진한 `#7B5CD6`로 위에서 흘러내리는 3갈래. 그 이하는 생략 (아이콘/02 GGUMI처럼 축소본은 실루엣만 남긴다)
- 팔: 앱 안에서는 없음. 포스터·영상 포즈에서만 캐릭터/02처럼 **굵은 잉크색 선 팔다리**를 붙인다
- ⚠️ `design/character/휘서_캐릭터_구버전.png`(앞머리·목 있는 안)는 규칙 1(목 만들지 말 것)과 충돌 → **폐기 확정 필요**

### 1-2. 두 개의 축 — 불꽃은 '단계', 눈은 '순간'

앱에 이미 **불꽃 단계(3/4)** 시스템이 있다. 캐릭터가 그것을 직접 보여준다.

**불꽃 = 함께 꺼낸 이야기 수** (프로필의 진행 바를 대체)

| 단계 | 불꽃 |
| :-- | :-- |
| 0 · 꺼짐 | 없음. 심지만. 눈 감음 (온보딩 '불 켜기' 화면) |
| 1 | 작은 물방울 하나 |
| 2 | 물방울, 키가 왁스의 1/2 |
| 3 | 두 갈래, 키가 왁스와 같음 |
| 4 | 세 갈래, 왁스보다 큼 — 캐릭터/03 'joy' 실루엣 |

**눈 = 지금 이 순간** (캐릭터/03의 9종 중 5종만 채택. angry·sly는 휘서 세계관에 없음)

| 상태 | 눈 | 앱에서 쓰는 자리 |
| :-- | :-- | :-- |
| watching | 동그란 눈, 입 점 | 기본. 대화 목록 · 헤더 |
| friendly | 동그란 눈, 작은 미소 | 온보딩 인사 · 푸시 배너 |
| confusion | 한쪽 눈 기울임 | **생각 중** (점 세 개 대신 헤더 아바타 눈이 바뀐다) |
| joy | 감은 눈 + 벌린 입 | 이야기 완성 |
| sleep | 감은 눈 ‿ ‿ | 불 켜기 전 · 알림 끈 상태 |

### 1-3. 크기별 3단계 (아이콘/02 GGUMI 턴어라운드 방식)

| 크기 | 무엇이 남는가 | 쓰는 곳 |
| :-- | :-- | :-- |
| **24px 마크** | 불꽃 + 왁스 실루엣만. 눈 없음 | 탭바 · 파비콘 · 말풍선 옆 · '오늘의 이야기' 배지 |
| **40~64px** | + 눈 | 헤더 아바타 · 목록 |
| **120px+** | + 촛농 3갈래 + 스캘럽 밑단 | 온보딩 · 프로필 · 스플래시 · 인쇄물 |

### 1-4. 앱 아이콘 — 두 안

| | A. 얼굴 크롭 | B. 2도형 마크 |
| :-- | :-- | :-- |
| 레퍼 | 아이콘/01 (노랑 바탕, 얼굴 크게 잘림) | 아이콘/10~13 (불꽃+왁스 마크) |
| 구성 | 노랑 `#FFD54A` 바탕, 캐릭터를 아이콘 폭의 140%로 키워 눈과 불꽃만 보이게 | 보라 `#7B5CD6` 바탕, 노랑 불꽃 + 연보라 왁스 두 도형, 얼굴 없음 |
| 장점 | 홈 화면에서 "친구"로 읽힘. 레퍼 방향과 가장 가까움 | 축소·단색·인쇄 전부 강함. 영상·부스 사인물과 공유 가능 |
| 추천 | **앱 아이콘 = A** | **파비콘·탭바·영수증·사인물 = B** |

현재 아이콘(그라데이션 연보라 배경)은 두 안 어느 쪽에도 없으므로 교체.

## 2. UI 수정안

### 2-1. 색 — 흐린 원을 지우고 면으로

`Blobs` 컴포넌트(흐린 원 10개) 삭제. 대신 **화면당 색면 하나.**

| 화면 | 지금 | 제안 | 레퍼 |
| :-- | :-- | :-- | :-- |
| 스플래시 | 흰 바탕 + 188px 캐릭터 + 흐린 원 | **보라 `#7B5CD6` 풀블리드.** 캐릭터를 화면 폭 110%로 키워 하단에서 잘리게. `輝敍`는 노랑 | main-ui/05 po, 04 Langvi 첫 장 |
| 온보딩 불 켜기 | 흰 바탕 + 연보라 원 | 어두운 보라 `#3D2A7A` 풀블리드. 꺼진 초 하나. 누르면 화면이 **노랑으로 바뀌며** 불이 켜진다 — 색 전환 자체가 '불 켜기' | ui-ux/08 Suntera (기분 = 화면색) |
| 온보딩 인사 3스텝 | 흰 바탕 + 원 + 작은 말풍선 | 상단 45% 색 웨이브(보라→노랑→보라 순환) + **굵은 헤드라인 28px**, 하단 흰 면에 캐릭터 + 입력 | main-ui/02 곰 온보딩 |
| 대화 목록 · 대화 · 서랍 · 나 | 흰/크림 | **그대로 흰색.** 기능 화면은 색을 쓰지 않는다 | Tang, Moe, Ahead |
| 이야기 완성 | 크림 + 사진 카드 | 흰 바탕 유지. 상단에 **joy 눈의 64px 캐릭터**가 배지 자리를 대신함 | 레퍼런스/README "장난기는 진입과 결과에" |
| 휘서 프로필 | 흰 + 원 + 진행 바 + 3/4 | 보라 풀블리드. **캐릭터 불꽃이 단계 그 자체** → 진행 바·'3/4' 삭제. 숫자는 '함께 꺼낸 이야기 3' 하나만 | main-ui/05 po |

### 2-2. 지울 것 (규칙에 이미 있지만 코드에 남아 있는 것)

- `--shadow-btn` 노랑 글로우, `--shadow-sm/md` 카드 그림자 → **전부 삭제.** 레퍼는 그림자가 없다
- 휘서 말풍선의 흰 면 + 그림자 → **연보라 `#EDE7FF` 평면** (레퍼런스/README에 이미 확정된 값. 코드가 안 따라감)
- 말풍선마다 붙는 24px 캐릭터 → 삭제. 헤더 아바타 하나로 충분. 대신 24px **마크**(1-3)로 대체하거나 아예 없앰
- 대화 헤더의 민트 접속 점 → 삭제 (8/27 "보라·노랑 두 색만")
- `--mint`, `--coral` 토큰 → 삭제

### 2-3. 남길 것

- 알약형 버튼 — 레퍼 전부 알약. (`hwiseo-design-rules.md`의 '4px 반경'은 다크 시절 규칙, 라이트 방향에선 무효)
- 말풍선 꼬리 — poster/05처럼 꼬리가 캐릭터성을 준다
- 탭 3개 구조, 명조 이야기 화면

### 2-4. 타이포 — 캐릭터와 같은 무게로

| 자리 | 지금 | 제안 |
| :-- | :-- | :-- |
| 온보딩 헤드라인 | 16px 말풍선 안 문장 | **Pretendard Bold 28/36**, 색면 위에 흰색 또는 잉크. 말풍선 밖으로 꺼낸다 |
| 페이지 제목(대화·서랍·나) | 24 Bold | 유지 |
| 이야기 한 줄 정리 | 22 Bold 고딕 | **명조 24 Bold** — 본문과 같은 서체로 무게만 |
| CTA | 15 Bold | 16 Bold, 잉크색 |

### 2-5. 화면당 '파격 하나' 다시 배정

| 화면 | 파격 하나 |
| :-- | :-- |
| 스플래시 | 화면 밖으로 잘린 거대 캐릭터 |
| 불 켜기 | 탭 한 번에 화면색이 어둠→노랑 |
| 온보딩 | 상단 색 웨이브 |
| 대화 | 노랑 말풍선 (유일한 채도색) |
| 이야기 | 명조 + joy 캐릭터 |
| 프로필 | 불꽃 크기 = 단계 |
