# 휘서 핵심 화면 구성 (2026-08-31 초안)

> 불꽃 단계·아바타 기능은 보류. 화면 5개의 역할과 구성만 정한다.
> 탭은 **홈 · 아카이브 · 나** 셋. 채팅은 탭이 아니라 홈에서 들어가는 화면.

---

## 0. 한 줄 정의

| 화면 | 역할 한 줄 | 무대/기능 |
| :-- | :-- | :-- |
| 온보딩 | 휘서가 누군지 알고, 이름 하나 남기고, 15초 안에 첫 사진으로 | 무대 (보라) |
| **홈** | **오늘 사진 한 장을 시작하는 곳** + 하다 만 대화 이어가기 | 무대 상단 + 기능 하단 |
| 채팅 | 사진 한 장을 두고 묻고 답하다가 이야기 한 편이 되는 곳 | 기능 (흰색) |
| 아카이브 | 완성된 이야기를 다시 읽는 곳 | 기능 (흰색) |
| 나 | 이름 · 알림 · 언어 · 데이터, 그리고 휘서 소개 | 기능 (흰색) |

**홈과 아카이브의 경계 = "완성 여부".**
진행 중인 대화는 홈에, 이야기로 정리된 것은 아카이브에. 지금 앱의 '대화 목록' 탭은 없앤다 — 목록이 홈의 일부가 된다.

## 1. 온보딩 — 4스텝, 한 화면에서 문장만 바뀜

```
[A0] 언어           ENGLISH / 한국어  (텍스트 둘뿐)
[A1] 인사           캐릭터 크게 + "안녕하세요, 저는 휘서예요." + 뭘 하는지 2줄
[A2] 이름·프로필    "뭐라고 부를까요?"  입력 하나 + 프로필(사진 고르기 / 단색 5개 중 하나)
[A3] 알림 주기      주 1회 / 2주 / 한 달  (푸시 미리보기 카드)
      ↓ "시작하기"  →  홈 (첫 방문이면 홈의 CTA가 곧 첫 사진)
```

- 보라 풀블리드, 캐릭터는 A1에서만 크게. A2·A3는 캐릭터가 작아지고 위로 물러남
- 건너뛰기 항상 보임. 알림은 나중에 '나'에서 바꿀 수 있음
- 튜토리얼 카드 ✗. 문장이 바뀌는 것으로 충분

## 2. 홈 — "오늘 사진 한 장"

홈이 하는 일은 셋뿐이다. 순서대로 위에서 아래.

```
390 × 844
┌─────────────────────────┐
│ 輝敍            [나] ○  │  ← 상단: 마크 + 프로필 진입
│                         │
│   (휘서, 화면 밖으로     │  무대 영역 · 보라
│    잘리게 크게)          │
│                         │
│  민지님, 3일 만이에요.   │  ← 인사 한 줄 (마지막 대화 기준)
│  오늘은 어떤 사진이      │
│  있나요?                │
│                         │
│ ┌─────────────────────┐ │
│ │  + 사진 고르고 시작   │ │  ← ① 유일한 노랑 CTA
│ └─────────────────────┘ │
├─────────────────────────┤  ← 여기서 흰색으로
│ 이어서 하기              │  ② 하다 만 대화 (없으면 이 블록 없음)
│ ▣ 8월 21일 · 3턴 진행   │
│   "김밥 두 줄이었는데…"  │
│                         │
│ 최근 이야기        전체 →│  ③ 아카이브 미리보기 2~3장
│ ▣ ▣ ▣                   │
│                         │
│  [홈]   [아카이브]  [나] │
└─────────────────────────┘
```

| 블록 | 무엇 | 왜 홈에 |
| :-- | :-- | :-- |
| ① 시작 | 사진 고르기 → 채팅 | 이 앱의 유일한 행동. 홈의 존재 이유 |
| ② 이어서 하기 | 완성 안 된 대화 (보통 0~1개) | 사진마다 대화가 분리되니 "돌아갈 자리"가 필요 |
| ③ 최근 이야기 | 완성된 것 2~3장 → 아카이브 | 아카이브 탭까지 안 가도 "쌓이고 있다"가 보여야 함 |

- 인사 한 줄은 **상태**를 말한다: 첫 방문 / N일 만 / 이어서 할 대화 있음 / 알림으로 들어옴
- 홈에 통계·달력·업적 ✗. 사진 한 장을 여는 데 필요한 것만

## 3. 채팅 — 사진이 위에 고정된 대화

```
┌─────────────────────────┐
│ ‹    2019 · 03   정리하기 │  ← 시기(휘서 추정→고침) · 정리하기는 헤더에 조용히
│ ┌─────────────────────┐ │
│ │       사진          │ │  ← 상단 고정. 스크롤하면 작아지되 안 사라짐
│ └─────────────────────┘ │
│ ┌────────────────┐      │
│ │ 실내에서 여럿이… │      │  휘서 · 연보라 면
│ └────────────────┘      │
│       ┌────────────────┐│
│       │ 동아리 종강…    ││  나 · 노랑 면
│       └────────────────┘│
│ ┌────────────────┐      │
│ │ 그날 그 자리에… │      │
│ └────────────────┘      │
│                         │
│                         │  ← 대화 중간 개입 없음 (앱은 턴 무제한)
│ ─────────────────────── │
│  답을 적어주세요      ↑  │
└─────────────────────────┘
```

- 말풍선 옆 캐릭터 ✗. 헤더에도 없음 — 휘서의 존재는 질문과 연보라 면으로만
- **정리하기** = 헤더 우측 텍스트. 누르면 바텀시트 "지금까지를 이야기로 정리할까요? / 조금 더" 한 번만 확인. **3턴 규칙은 전시 모드 전용** — 앱에서는 턴 수를 세지도, 보여주지도 않는다
- 사진 시기 고치기·이 대화 지우기는 시기 칩 탭
- **결과 화면(이야기 완성)** 은 채팅의 마지막 장: 사진 + 한 줄 제목 + 이야기 본문(명조) + "아카이브에 저장됨" + [다른 사진으로]

## 4. 아카이브 — 완성된 이야기만

```
┌─────────────────────────┐
│ 아카이브                 │
│ 12편 · 2019 ~ 2025      │  ← 보조 한 줄
│                         │
│ ┌────────┐ ┌────────┐   │
│ │  사진  │ │  사진  │   │  2열 그리드
│ │ 8월 21 │ │ 8월 14 │   │  날짜 = 대화한 날, 시기 = 사진의 해
│ │ 엄마는  │ │ 우산이  │   │  한 줄 제목
│ └────────┘ └────────┘   │
│ ┌────────┐              │
│                         │
│  [홈]   [아카이브]  [나] │
└─────────────────────────┘
```

- 탭하면 결과 화면과 같은 **이야기 상세**: 사진 · 제목 · 본문 · 대화 다시 보기(접힘)
- 정렬은 대화한 날 최신순. 필터·검색은 12편 넘을 때 생각
- 삭제는 상세의 `···`에서만

## 5. 나 — 설정 + 휘서 소개

```
┌─────────────────────────┐
│ 나                      │
│ ● 민지      [프로필 고치기]│  프로필(사진 또는 단색) + 이름
│                         │
│ 알림    주 1회         › │
│ 언어    한국어         › │
│                         │
│ 휘서에 대해            › │  ← 캐릭터 소개 (온보딩 A1을 다시 보는 자리)
│ 이 앱에 대해           › │
│                         │
│ 모든 기록 지우기         │  빨강 텍스트 하나
│                         │
│  [홈]   [아카이브]  [나] │
└─────────────────────────┘
```

- 지금 앱의 '휘서 프로필'(불꽃 단계·통계)은 **'휘서에 대해'** 한 줄로 축소. 무대 화면(보라)으로 캐릭터 크게 + 소개 3줄
- 사진은 저장하지 않는다는 문장은 '이 앱에 대해'에

## 6. 흐름

```
첫 실행   스플래시 → A0 → 불 켜기 → A1 → A2 → A3 → 홈(첫 방문 인사) → 사진 → 채팅 → 결과 → 홈
평소     스플래시 → 불 켜기 → 홈("N일 만이에요") → 사진 → 채팅 → 결과 → 홈

불 켜기 = 진입 의식. 켜기 전엔 시간과 무관하게 어둡고(아직 휘서가 없음), 초를 누르면 불꽃이 붙으며 그 시각의 하늘로 밝아지고 휘서가 인사한다.
          홈 → 이어서 하기 → 채팅
          홈/아카이브 → 이야기 상세
```

## 7. 지금 앱에서 바뀌는 것

| 지금 | 제안 |
| :-- | :-- |
| 탭: 대화 · 서랍 · 나 | 탭: **홈 · 아카이브 · 나** |
| 대화 목록 화면 | 없앰 → 홈의 '이어서 하기' + 아카이브 |
| 휘서 프로필 (불꽃 3/4, 통계) | 없앰 → '나 › 휘서에 대해' |
| 서랍 | 아카이브 (이름만 바뀜, 상세 화면 추가) |
| 스플래시 | 유지, 무대 화면으로 |

## 9. 무드 기준 — Langvi (`design/ref/ui/langvi-screens.png`)

사용자 OK한 무드. 이 레퍼가 좋은 이유를 규칙으로 뽑는다.

| 레퍼에서 | 휘서에 적용 |
| :-- | :-- |
| 캐릭터 **3가지 크기**만 씀: 화면 밖으로 잘린 거대 얼굴 / 전신 / 셀·칩 크기 얼굴 | 거대 얼굴 = 스플래시·온보딩 A1·홈 상단·'휘서에 대해' / 전신 = 결과 화면·빈 상태 / 얼굴 칩 = 카드 모서리·탭 아이콘 |
| 로그인 화면: 노랑 얼굴이 상단 절반을 꽉 채우고 좌우가 잘림 | 홈 상단 무대. 얼굴 하나가 곧 배경 |
| 화면 = **위 색면(무대) + 아래 흰색(기능)** 딱 두 층, 경계는 곡선 | 홈·채팅 결과·온보딩 전부 같은 두 층 |
| 카드마다 **다른 단색** + 캐릭터가 카드 모서리에서 잘려 나옴 | 온보딩 A3 알림 주기 3카드(주1회/2주/한달)에 사용 — 사진 카드에는 ✗ (사진이 주인공) |
| 그림자·그라데이션·글로우 없음, 모서리 크게 둥글게 | 이미 결정. 반경 24~28 |
| 무대 아래 **진행 바 + ▲ 마커** | 채팅 상단: 사진 아래 턴 진행 (3턴) |
| 하단 **색 띠 안에 CTA** (라임 띠 + 초록 버튼) | 채팅 "이야기로 정리하기": 노랑 띠 + 잉크색 버튼 |
| 캐릭터 말풍선으로 숫자 한 줄 ("15분 공부했어요") | 결과 화면: "이야기 한 편이 됐어요" / 홈: "3일 만이에요" |
| 달력 셀이 전부 표정 | 보류 — 아카이브는 사진 그리드. 표정 셀은 아바타 기능 재개 때 |
| 5색: 보라 / 딥보라 / 노랑 / 회베이지 / 핑크·하늘 | 보라 `#7B5CD6` / 딥보라 `#3D2A7A` / 노랑 `#FFD54A` / 회백 `#E6E3DE` / 연보라 `#EADFEE` — 5개 고정 |
| 큰 제목 한 줄 + 아주 작은 라벨, 중간 크기 거의 없음 | 제목 32 / 본문 16 / 라벨 12. 이야기 본문만 명조 |

레퍼와 다른 점 하나: 휘서는 **아웃라인이 있다**. 거대 얼굴로 쓸 때 선 두께는 화면 폭 기준 2.5px로 고정(스케일 따라 두꺼워지지 않게).

## 10. 하늘(시간별) 톤 — 9/1 추가, 프로토 기본값

| 시간 | 무대 | 구름 3겹 | 장식 | 무대 텍스트 | 패널 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 아침 6–11 | `#C9BCE6` | `#D9CFEF` `#EAE4F7` `#FFF` | 해 | 보라 | `#F1EDF8` |
| 낮 11–17 | `#A99BD1` | `#BDB2DE` `#D2CAEA` `#E6E1F3` | 해 | 딥보라 | `#ECE7F6` |
| 저녁 17–20 | `#6E5A9E` | `#7F6BB0` `#9B84BE` `#C69EC6` | 별 (옅게) | 흰 | `#E3DAF1` |
| 밤 20–6 | `#4A3B7C` | `#5D4D96` `#7A66B5` `#8F79BE` | 별 | 흰·레몬 | `#DCD3EF` |

- 바뀌는 건 **무대 배경뿐** (색·구름·별·해). 패널·CTA·카드·탭·캐릭터·말풍선은 밝음 톤 그대로 (9/1 확정)
- 흰 하늘 ✗ — 노랑 캐릭터 대비 때문에 전부 보라 계열 안에서 명도만 이동
- 캐릭터: 밝음 톤 그대로 (아웃라인 유지). 무아웃라인 밤 스킨은 폐기 (`mock-0901-night.html` 참고용)
- 그림자·글로우 여전히 ✗. 구름은 배경 장식으로만
- 전시 모드는 밤 고정 옵션
- 앱 구현: `new Date().getHours()` → `data-sky` 속성 → CSS 변수 세트. 경계 시각 전환은 `transition .8s`
