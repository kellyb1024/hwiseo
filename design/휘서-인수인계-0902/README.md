# 휘서(輝敍) 앱 디자인 인수인계 — 2026-09-02

사진 한 장을 보고 **AI 친구 휘서**가 질문을 던지고, 답하다 보면 그날의 이야기 한 편이 되는 앱.
휘서는 사진을 볼 수는 있지만 그 순간을 겪지는 못했다. 그래서 묻고, 답을 들을수록 불이 자란다.

## 1. 색 — 쨍한 보라 + 쨍한 노랑

`01-디자인시스템/hwiseo-palette.md` 가 단일 기준. **새 색을 만들지 않는다.**

| 토큰 | HEX | 자리 |
| :-- | :-- | :-- |
| `--main` | `#FFD54A` | 노랑 = **사람**. 내 말풍선, CTA, 활성 |
| `--main-deep` | `#F5B92E` | 탭 활성 아이콘, 촛농 |
| `--main-pale` | `#FFF3CE` | 연한 강조면 |
| `--sub` | `#7B5CD6` | 보라 = **휘서**. 무대 배경, 링크성 텍스트 |
| `--sub-pale` | `#EDE7FF` | 캐릭터 뒤 면, 휘서 말풍선 |
| `--ink` | `#1D1B22` | 본문 제목 |
| `--body` / `--muted` | `#5D5866` / `#94909E` | 본문 / 보조 |
| `--mint` / `--coral` | `#3ECFBB` / `#FF8A6B` | 프로필 색 선택지 |

**하지 않을 것**
- ✗ 파스텔·톤다운 (먹보라 `#4A3B7C`, 라일락 패널, 파스텔 하늘 — 전부 폐기안)
- ✗ **진보라 `#3D2A7A`** — 팔레트에 없는 색. 작은 글씨에서 붉게 보임. 텍스트는 잉크, 링크·활성만 `#7B5CD6`
- ✗ 구름·별·해 장식, 그라데이션, 그림자, 글로우
- 무대는 **단색 쨍한 보라 하나.** 시간대별 배경 변화는 보류

**구조:** 위 보라 무대 + 아래 흰 패널 두 층, 경계는 곡선(웨이브). 대표 무드 = `05-레퍼런스/무드-시안A-대표.jpg`

## 2. 타이포 — 규칙은 `hwiseo-design-rules.md` 3장

**서체** (한 화면 2패밀리까지)
- Pretendard — 휘서의 질문·UI
- Noto Serif KR — 사람의 이야기 (결과·상세 화면 본문만)
- IBM Plex Mono — 연도·턴·시각, 극소량

**스케일 6단계** (390px 기준)

| 역할 | 크기 / 행간 |
| :-- | :-- |
| 질문 | 22 / 32 |
| 이야기(명조) | 18 / 30 |
| 확인 문장 | 17 / 26 |
| 입력·답변 | 16 / 24 |
| 안내·보조 | 14 / 20 |
| 라벨 | 12 / 16 |

**굵기 — 위계를 굵기로 만들지 않는다.** Regular 하나, 필요하면 SemiBold 하나만. 위계는 **크기 + 명도**로.

✅ **프로토 정리 완료 (9/2)** — 크기 18종 → **6단계**(12·14·16·17·18·22 + 스플래시 브랜드 64는 파격 1개), 굵기 4종 → **2종**(본문 400 / 강조 600). 이야기 본문은 명조 18/30.

## 5. 화면 16개

세부 와이어·문안은 `03-화면/hwiseo-screens-0831.md`, 클릭 프로토는 `proto-0901-A.html`

```
첫 실행  스플래시 → 불 켜기 → A0 언어 → A1 인사 → A2 이름·프로필 → A3 알림
         → 홈(첫 방문) → 사진 고르기 → 채팅 → 정리하기 → 결과 → 홈
평소     스플래시 → 불 켜기 → 홈 → 사진 → 채팅 → 결과
         홈 › 이어서 하기 → 채팅
         홈 / 서랍 → 이야기 상세
         나 › 휘서에 대해
```

**탭 3개: 홈 · 서랍 · 나**

- **불 켜기** — 진입 의식. 꺼진 초를 탭하면 불이 붙고 화면이 밝아지며 휘서 등장
- **홈** — ① 사진 고르고 시작(유일한 노랑 CTA) ② 이어서 하기(있을 때만) ③ 최근 이야기 2~3장
- **채팅** — 사진 상단 고정, 캐릭터 ✗, **중간 개입 없음**(턴 표시·독촉 ✗). '정리하기'는 헤더 우측에 조용히 → 바텀시트로 한 번 확인
- **결과·상세** — 사진 + 한 줄 제목 + 이야기 본문(명조)
- **서랍** — 완성된 이야기 2열 그리드
- **나** — 이름·프로필 / 알림 / 언어 / 휘서에 대해 / 이 앱에 대해 / 기록 지우기

> 3턴 규칙은 **전시 모드 전용**. 앱은 턴 무제한.
