## 일러스트에서

- **레이어 패널에 한글 이름**으로 뜹니다 — 그림자 / 휘서 / 포즈 / 몸통 / 촛농 / 윗면 / 심지 / 불꽃 / 눈 / 동공 / 입 / 볼 / 팔 / 발 / 소품
- **촛농은 클리핑 마스크**로 몸통 안에 들어가 있어요. 흐름 모양을 바꾸려면 `오브젝트 › 클리핑 마스크 › 해제`
- 아웃라인(선) 없음 — 전부 면(fill). 선을 넣으려면 몸통-면에 직접 추가
- 캔버스 420×420 정사각, 캐릭터 중심 x150 · 바닥선 y316
